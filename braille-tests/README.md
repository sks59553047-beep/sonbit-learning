# 한글 점자 변환 엔진 시험

- 엔진: `assets/braille-core.js`(한글·로마자·기호) + `assets/ueb-g2.js`(영어 낱말 약자) — 「한국 점자 규정」(문체부고시 제2024-0005호, 2024.3.1. 시행)의 한글 점자 제1~74항 중
  제1~2장(자모·약자·약어), 제4장 로마자(대문자 약어, 영어 낱말·섞인 낱말·하이픈·아포스트로피 낱말 = 통일영어점자 2급 약자, 제28~37항), 제5장(숫자 제40~44항),
  제6장(문장 부호·기타 부호 제49~64항 일부), **제65~72항 기호(화폐·단위·화살표·자주 쓰는 기호·글머리 가운뎃점, 2026-11-22)**를 구현.
- 시험: `node run-all.mjs` — 수동 정리 예시(manual-cases.json), 규정 본문에서 뽑은 고정 예시(frozen-cases.json), 로마자 예시(roman-cases.json), 기호 예시(symbol-cases.json)를 엔진 결과와 점 하나까지 대조하고,
  영어는 공개 점자 변환기(liblouis)와 견준 고정본(ueb-frozen.json 3,485개, ueb-frozen-pieces.json 660개)도 본다. 범위 밖 영어는 「지원 안 함」으로 나오는지도 본다. 하나라도 다르면 실패.
- 규정 본문: `source/regulation-2024.txt`(국립국어원 자료실 PDF에서 추출). 예시의 점자는 규정에 실린 ASCII 점자 표기 그대로.
- 검수용 표: `점자_검수용_예시표.csv` — 점자 교사·복지관 검수용.

## 지원하지 않는 것(표시만 하고 바꾸지 않음)
세 낱말 넘게 이어진 대문자 구절(대문자 구절표), 한 글자 영어 낱말, IoT처럼 대문자 한 글자로 끝나는 섞인 낱말, 그리스 문자(제30~31항), 옛 글자(제3장), 연산·비교 기호·분수(제45~47항),
강조·숨김·빠짐표(제56~58항), 점역자 주표·점형표·일반 첨자(제66~68항), 글머리 ○□△와 빈칸(제72~73항 일부), 컴퓨터 점자(주소·이메일·파일 이름, 제74항),
국제음성기호, 줄 끝에서 이어 쓰는 연결표(제42·44항), 단독 자음의 번호·붙임(제9~10항), 수학·과학·음악·외국어 점자.
규정 쪽 27~55에서 뽑은 예시 가운데 위 범위 밖인 것이 40여 개 남아 있다(`node run-regulation.mjs 27 55`로 볼 수 있음 — 설명 문장이 섞여 추출되는 잡음도 있음).

## 알려진 해석
- 줄이 바뀔 때의 예외(제11·12·14항 다만)는 입력에 줄바꿈(\n)을 넣으면 적용된다. 일반 글에서는 줄바꿈 위치를 알 수 없어 적용하지 않는다.
- 줄임표: … 한두 개는 ,,, / 마침표 세 개 또는 여섯 개는 444.
- 키보드 따옴표(" ')는 열고 닫는 모양으로 번갈아 해석한다.
- 숫자 사이의 -는 붙임표(36)로 바꾼다(빼기 기호일 수 있어 경고를 띄움).
- 로마자(대문자): 흔한 영어 낱말 목록(assets/ueb-g2.js, 4글자 이상)에 있는 대문자 낱말(OPEN·STOP)은 영어 약자를 쓰고, 그 밖의 다섯 글자 이하 대문자는 글자를 하나씩 읽는 약어로 보고 영어 약자를 쓰지 않는다(규정 예시 WHO·KTX·SNS 등과 같음).
  영어 줄임말(shortform)과 같은 글자 조합(CD = could, SD = said 등)이나, 덩어리 첫 단어가 아닌 홀로 쓴 한 글자(A·I·O 제외) 앞에는 1급 점자표(56)를 적는다(규정 예시 「CD 1장」·「George V」).
  덩어리 첫 단어로 홀로 쓴 한 글자에는 적지 않는다(규정 제36항 「V」 0,v4).
  「LP 1장」처럼 대문자 단어 뒤에 빈칸과 숫자가 오면 숫자까지 한 덩어리로 보고 종료표를 적지 않는다(제35항).
