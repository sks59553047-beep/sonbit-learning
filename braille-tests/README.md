# 한글 점자 변환 엔진 시험

- 엔진: `assets/braille-core.js` — 「한국 점자 규정」(문체부고시 제2024-0005호, 2024.3.1. 시행) 제1~2장(자모·약자·약어), 제5장(숫자 제40~44항), 제6장(문장 부호 제49~54항 일부)을 구현.
- 시험: `node run-all.mjs` — 수동 정리 예시(manual-cases.json)와 규정 본문에서 뽑은 고정 예시(frozen-cases.json) 전부를 엔진 결과와 점 하나까지 대조. 하나라도 다르면 실패.
- 규정 본문: `source/regulation-2024.txt`(국립국어원 자료실 PDF에서 추출). 예시의 점자는 규정에 실린 ASCII 점자 표기 그대로.
- 검수용 표: `점자_검수용_예시표.csv` — 점자 교사·복지관 검수용.

## 지원하지 않는 것(표시만 하고 바꾸지 않음)
로마자·그리스 문자(제4장), 옛 글자(제3장), 연산·비교 기호·분수(제45~47항), 강조·숨김·빠짐표 등 기타 부호(제56~58항 등), 줄 끝 연결표(제42항), 단독 자음의 번호·붙임(제9~10항), 수학·과학·음악·외국어 점자.

## 알려진 해석
- 줄이 바뀔 때의 예외(제11·12·14항 다만)는 입력에 줄바꿈(\n)을 넣으면 적용된다. 일반 글에서는 줄바꿈 위치를 알 수 없어 적용하지 않는다.
- 줄임표: … 한두 개는 ,,, / 마침표 세 개 또는 여섯 개는 444.
- 키보드 따옴표(" ')는 열고 닫는 모양으로 번갈아 해석한다.
- 숫자 사이의 -는 붙임표(36)로 바꾼다(빼기 기호일 수 있어 경고를 띄움).
