# 손빛 배움터 시험

사이트를 고친 뒤 사이트에 올리기 전에 돌리는 자동 시험입니다. 화면 없는 크롬을 띄워 실제로 버튼을 누르고, 결과를 확인합니다.

## 준비

설치할 것이 없습니다. Node.js 22 이상과 구글 크롬만 있으면 됩니다(크롬 위치가 기본과 다르면 `CHROME` 환경 변수로 알려 주기).

## 돌리기

| 명령 | 하는 일 | 걸리는 시간 |
|---|---|---|
| `node tests/run-all.mjs` | 내 컴퓨터 파일로 전부 | 15분 안팎 |
| `node tests/run-all.mjs --quick` | 오래 걸리는 시험(종합·기능 전체·좁은 화면 등)을 빼고 | 5분 안팎 |
| `node tests/run-all.mjs --live` | 실제 주소(https://sonbit.pages.dev)로, 올린 뒤 확인 | 15분 안팎 |

시험용 서버(127.0.0.1:8765)와 크롬(디버그 포트 9333)은 실행기가 알아서 켜고 끕니다. 시험이 만드는 그림과 임시 파일은 `tests/out/`에 생기고 git에는 올라가지 않습니다.

`lib/cdp.mjs`는 크롬을 조작하는 도우미, `lib/serve.mjs`는 시험용 서버입니다. 시험용 서버는 `functions/api`의 진짜 함수 코드를 그대로 돌리고, Cloudflare D1 대신 내 컴퓨터 메모리의 SQLite(`lib/dev-api.mjs`, `board/schema.sql`)를 씁니다. 그래서 게시판 시험은 진짜 게시판에 글을 남기지 않습니다.

## 오류 자동 보고

사이트(`assets/error-report.js`)가 사용자 화면의 오류를 `/api/error`로 보내면, Cloudflare 함수(`functions/api/error.js`)가 GitHub 이슈(라벨 `auto-error`)로 올립니다. 개인정보는 보내지 않습니다. GitHub 열쇠는 Cloudflare 비밀값 `GITHUB_TOKEN`(이 저장소 이슈 쓰기 권한만)에만 있습니다. 사이트를 올릴 때 `functions` 폴더를 wrangler 를 실행하는 폴더에 함께 두어야 함수가 같이 올라갑니다.

새 오류 확인: `gh issue list --label auto-error`

## 의견 게시판

글은 Cloudflare D1 저장소 `sonbit-board`(표 구조: `board/schema.sql`)에 저장되고, `functions/api/board`(읽기·쓰기·신고)와 `functions/api/admin/board`(관리)가 다룹니다. 저장하는 것은 글과 시각뿐이고, 접속 주소는 비밀값 `BOARD_SALT`를 섞어 알아볼 수 없게 바꾼 값으로만 도배 제한과 중복 신고 막기에 씁니다. 일반 게시판처럼 목록(번호·제목·글쓴이·날짜·조회, 쪽 번호, 검색) → 글 보기(+댓글) → 글쓰기 구조이고, 글·댓글은 쓸 때 정한 비밀번호로 본인이 고치거나 지울 수 있습니다(비밀번호는 무작위 값과 섞어 바꾼 값만 저장). 욕설이 든 글·제목·댓글·닉네임은 받지 않습니다(단어 목록 방식, `functions/_lib/badwords.js`. 다른 뜻으로 흔히 쓰는 말은 일부러 뺐으니 낱말을 더할 때는 `tests/board-words.mjs`에 통과해야 할 말도 같이 적고 돌려 볼 것). 관리 화면은 https://sonbit.pages.dev/admin 이고 비밀번호는 Cloudflare 비밀값 `ADMIN_PASSWORD`에만 있습니다(저장소에 적지 않음). 신고 3건으로 숨겨진 글·댓글이 생기면 GitHub 이슈(라벨 `board-report`, 글 번호만)로 알립니다.

신고로 숨겨진 글 확인: `gh issue list --label board-report`
